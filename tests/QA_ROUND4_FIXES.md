# RP LAND 4차 발견 사항 수정

2026-10-03. 문서·레스 ID 누락과 인증 비밀번호 자료형 오류를 수정했습니다.

- 문서 수정·삭제에서 대상 ID가 없으면 DB 조회 전 400으로 거부합니다.
- 레스 수정·삭제도 대상 ID를 먼저 확인하고 누락 시 400으로 거부합니다.
- 로그인·탈퇴·비밀글 열람의 비밀번호를 강제 문자열 변환하지 않습니다. 공통 인증 함수에서 문자열인지와 최대 128자인지 확인하고, 잘못된 값은 인증 실패(401)로 처리합니다.
- 가입 때와 달리 인증에는 새로운 최소 길이 규칙을 적용하지 않아 기존 인증 동작을 유지합니다. 비밀번호의 앞뒤 공백을 제거하지 않으며 저장된 비밀번호나 세션을 다시 쓰지 않습니다.

빌드에 성공했고, 격리 Worker/D1에서 기존 166개 검사와 자료형·길이·정상 로그인 회귀 20개를 합친 186개가 모두 통과했습니다. 이전 7개 실패 요청은 모두 의도한 4xx로 거부됐습니다. 잘못된 탈퇴 시도 후 계정과 정상 로그인 유지도 확인했습니다.

검증은 `pnpm run build` 후 `node tests/qa-round4.mjs`로 재실행할 수 있습니다. 원시 결과는 `qa-round4-fixed-results.log`입니다. 제한된 실행 환경에서는 임시 Worker/DB 실행이 차단되어, 허용된 실행 권한으로 격리 테스트를 수행했습니다. 운영 기록 초기화나 계정 재생성은 하지 않았습니다.
