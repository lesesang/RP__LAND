# RP LAND 3차 발견 사항 수정

2026-09-29. 이전 검증의 원인 기준 6종류를 수정했습니다. 운영 데이터 초기화나 기존 비밀번호 변경은 하지 않았습니다.

| 발견 사항 | 수정된 동작 |
|---|---|
| 가입 시 비밀번호 공백 제거 | 가입·비밀글 생성은 비밀번호를 원문 그대로 해시합니다. 로그인·열람·탈퇴 검증과 일치합니다. |
| Infinity·지나치게 큰 페이지 번호로 503 | 목록과 시간표에 공통 검증을 적용했습니다. 페이지 생략은 1, 명시한 값은 1~1,000,000의 정수만 허용하며 그 외에는 400입니다. |
| 카테고리 PATCH 대상 ID 누락으로 503 | ID를 먼저 확인하고 누락 시 400을 반환합니다. |
| 잘못된 예약 객체로 503 | 날짜 변환 전에 문자열과 길이를 확인합니다. 잘못된 자료형·날짜는 400입니다. |
| 예약 공개 옵션의 자료형 오류를 허용 | 공개 옵션은 생략 시 기존 기본값, 명시 시 boolean만 허용합니다. metadata는 객체여야 하며 객체 내부의 각 옵션도 검사합니다. |
| 문자열 false를 비밀글 활성화로 해석 | isSecret에 boolean 이외의 자료형을 보내면 400을 반환합니다. |

공통 예약 검증은 예약 글 생성과 수정에 모두 적용됩니다. 잘못된 수정 요청으로 기존 내용과 공개 설정이 바뀌지 않는 것을 확인했습니다. 정상적인 false 설정은 비공개로 유지됩니다.

## 기존 계정 호환성

저장된 해시와 계정 세션을 재작성하지 않습니다. 이미 공백을 제거해 저장한 과거 비밀번호는 기존의 실제 인증 문자열로 계속 로그인합니다. 원래 입력했던 공백은 해시에서 복원할 수 없으므로 추측해 바꾸거나 새로운 trim 폴백을 추가하지 않았습니다. 현재 운영 테스트 계정 8개는 앞뒤 공백 없는 무작위 비밀번호로 만들어져 영향을 받지 않습니다.

새 비밀번호는 공백을 포함한 원문 길이를 검사하고 128자 이하로 제한하며, 공백만으로 된 값은 거부합니다. 로그인 및 탈퇴는 원문으로 비교합니다.

## 검증

- 빌드 성공.
- 격리 Worker/D1 악의적 입력 및 수정 회귀 검증 152개 통과. 기존 116개와 새 회귀 36개를 포함합니다.
- 정확한 공백 비밀번호 로그인·비밀글 열람·탈퇴, 공백 제거 문자열 거부를 확인했습니다.
- 페이지 경계값, 생략 및 false 설정, 잘못된 예약 수정 후 원문 보존을 확인했습니다.
- 원시 로그: `qa-round3-fixed-results.log`.

실행: `pnpm run build` 후 `node tests/qa-round3-fuzz.mjs`. 테스트 추가 중 서버 종료 시점 오류로 실행이 중단된 것을 바로잡은 후 전체를 통과했습니다. 최초 병렬 통합 검사에는 기형 JSON 검사 실패가 있었으며 최종 검증 결과를 아래에 별도로 기록합니다. 화면 배치 변경은 없으며 이번 검증은 API 중심입니다.

최종 기존 통합 검증은 247개 모두 통과했습니다. 최초 기형 JSON 실패는 재현되지 않았습니다. 이 재실행에서는 진단용 fetch 래퍼로 연결 재사용을 끄고 5xx·전송 오류를 기록했으며 실패 응답을 재시도하거나 성공으로 보정하지 않았습니다. 별도 악의적 152개 스위트는 래퍼 없이 통과했습니다.
