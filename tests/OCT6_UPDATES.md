# 2026-10-06 기능 업데이트

- 주사위 최소·최대·개수·보정값을 텍스트 입력으로 변경. 정수 검증 후 양식을 삽입하며, 스피너/휠에 의한 값 변경 없음.
- 공개 전 예약은 기존 서버 목록/검색 제외 규칙을 유지하고, 작성 후 이동과 시간표 열람·편집을 시간표 경로로 통일. 공개 시각에는 일반 스레드로 이동. 이전 화면의 느린 응답이 현재 목록을 덮어쓰지 않도록 요청 순서 확인.
- 내 계정에서 저장 캐릭터 이름 삭제. 로그인 계정의 저장 목록만 변경하며 기존 레스와 다른 회원의 이름은 보존.
- 현재 비밀번호 확인 후 아이디/비밀번호 변경. 대소문자 무시 아이디 중복 검사, 입력 검증, 계정별 시도 제한. 변경과 전체 세션 폐기를 원자적으로 처리. 계정 ID, 역할, 글 소유권 유지.
- 사용법에 모든 꾸밈 버튼의 사용 순서와 문법, 이름 삭제와 계정 변경 동작 설명.
