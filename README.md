# RP LAND

한국어 친목 역할극 커뮤니티. React 19 / Vinext / Cloudflare Workers / D1 기반입니다.

## 구현 기능

- ID·비밀번호 회원가입, 로그인, 로그아웃, 탈퇴. 계정과 글은 D1에 저장합니다.
- 총관리자 / 부관리자 / 회원 역할. 총관리자만 부관리자 임명·해임, 회원 강제 탈퇴가 가능합니다.
- 스레드 본문 5,000자, 카테고리 최대 3개, 댓글 1,500자 및 스레드당 1,500개 제한. 가려진 댓글도 개수에 포함합니다. 동시 요청의 개수 제한을 SQL 조건부 INSERT로 처리합니다.
- 스레드·위키 공동 편집. 공동 편집자는 관리 권한, 권한 재공유, 댓글 가림 권한을 얻지 않습니다.
- 게시된 스레드·위키 삭제는 관리자만 가능합니다. 최신 버전만 저장합니다.
- 비밀 스레드의 제목만 검색 가능. 작성자·관리자도 비밀번호 확인 후 읽습니다. 열람 권한은 1시간짜리 HttpOnly 쿠키입니다. 비밀번호 원문은 누구에게도 제공하지 않으므로 작성자가 필요한 관리자에게 별도로 전달해야 합니다.
- 댓글 가림/해제는 스레드 작성자·관리자만 가능. 일반 스레드 댓글은 수정 불가. 사이트 전체 연습장 하나에서 본인 댓글만 수정 가능.
- 서버 암호학적 난수로 0~100,000,000 범위의 정수를 뽑고 최소·최대·개수·중복 제외·각 결과 보정값을 기록합니다. 일반 스레드 결과는 수정할 수 없으며 작은 보라색 배지로 표시합니다. 연습장에서는 수정 저장 시 다시 굴립니다.
- 캐릭터명 저장·재사용, 회원 목록, 카테고리 추가·이름 변경, 운영 감사 기록.
- 검색, 카테고리 필터, 페이지 나누기, 수동 갱신, 대표 이미지, 스레드별 계산기.
- 안전한 마크다운, 굵게/기울임/밑줄(`++텍스트++`)/목록/인용/코드/링크/이미지 주소 및 미리보기. HTML과 사용자 CSS는 실행하지 않습니다. 파일 업로드는 없습니다.
- 반응형 화면, 한국어 UI, 서울 시간 표시, 동작 줄이기 설정 반영.

## 총관리자 시작하기

1. 사이트에서 자신의 ID와 비밀번호로 가입합니다. 모든 신규 계정은 일반회원입니다.
2. 상단 자신의 계정 버튼 → 총관리자 설정에 창설자에게 별도로 전달된 설정 키를 입력합니다.
3. 총관리자가 한 명 지정되면 설정 키는 다시 사용할 수 없습니다. 키는 `ADMIN_SETUP_TOKEN` 서버 비밀값에만 저장하고 저장소에 커밋하지 않습니다.
4. 내 계정·관리에서 카테고리를 만들고 회원 목록에서 부관리자를 지정합니다.

배포한 Sites 주소는 처음에는 소유자 전용입니다. 커뮤니티 외부 회원에게 배포하려면 사이트 공개 범위를 별도로 설정해야 합니다. 앱의 ID/비밀번호 로그인과 Sites의 방문자 접근 범위는 별개입니다.

## 개발 및 배포

Node.js 22.13 이상 및 pnpm을 사용합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

논리 D1 바인딩은 `.openai/hosting.json`의 `DB`입니다. 스키마는 `db/schema.ts`, 마이그레이션은 `drizzle/`에 있습니다. 배포 시 Sites가 실제 DB 연결과 마이그레이션 적용을 처리합니다. 개인 Cloudflare Workers/D1 배포 설정과 PowerShell 순서는 [개인 D1 배포 안내](docs/personal-cloudflare-d1.md)를 참고하세요.

로컬 DB 준비(빌드 후):

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_curly_young_avengers.sql
node tests/run-local.mjs
```

테스트는 폐기 가능한 로컬 DB에서만 실행하세요. 테스트 계정과 문서를 생성하며 운영 DB에는 접근하지 않습니다.

## 보안 및 구현 결정

- PBKDF2-SHA256 100,000회와 사용자별 무작위 salt로 계정/비밀글 비밀번호를 저장합니다. Cloudflare Web Crypto 실행 한계 내 설정입니다.
- 세션 원문 대신 SHA-256 digest 저장, HttpOnly/Secure/SameSite 쿠키, 7일 만료, 탈퇴 시 세션 폐기.
- 쓰기 API의 Origin 및 JSON Content-Type 검사, 파라미터 바인딩 SQL, React 기반 마크다운 렌더링, 원시 HTML 무시.
- 비밀번호 시도는 15분 동안 대상당 20회 제한합니다. IP는 저장하거나 차단하지 않습니다.
- 본문/비밀번호/세션을 포함하지 않는 운영 감사 기록.
- 서버에서 모든 권한을 검사합니다. UI 숨김만으로 보호하지 않습니다.
- 이메일을 받지 않으므로 자동 비밀번호 복구는 지원하지 않습니다. 신규 운영 전 운영자가 복구 정책을 정해야 합니다.
- 문서의 댓글 수정 관련 모순은 더 엄격한 규칙으로 처리했습니다: 관리자도 일반 댓글 내용을 수정하지 못합니다.
- `search_threads` WebMCP 도구는 지원 브라우저에서 검색을 연결합니다. 이번 검증 브라우저에는 modelContext가 없어 실호출 검증은 불가능했습니다.

## 검증

`tests/api.integration.mjs`의 247개 검증이 통과했습니다. 가입/로그인, 타인 수정 거부, 공유 편집 및 권한 재공유 거부, 작성자 삭제 거부, 댓글 수정 제한, 숨김 데이터 차단, 주사위 검증, 입력 길이, 비밀글 본문 검색 제외와 쿠키 열람, 연습장 수정, 위키 공유, 탈퇴 후 세션 폐기와 글 보존, 관리자 권한, 카테고리 3개 제한, 숨긴 댓글을 포함한 1,500개 동시 요청 제한을 검증합니다.

## 2026-09-25 업데이트

- 총관리자·부관리자는 연습장을 포함한 레스를 삭제할 수 있습니다. 일반 스레드는 삭제 시 내용을 비우고 번호·누적 개수를 유지합니다. 연습장은 삭제한 레스를 완전히 제거하고 남은 번호를 다시 매기며 작성 가능 개수를 돌려줍니다.
- 주사위 버튼은 `[dice:2d6]` 양식을 입력 커서에 삽입합니다. 레스를 등록할 때만 서버에서 굴립니다. 한 레스에 여러 양식(최대 10개, 주사위 총 100개)을 사용할 수 있습니다. 코드 예시 안의 양식은 실행하지 않습니다. 일반 스레드는 수정할 수 없으며, 연습장은 주사위 유무와 관계없이 본인 레스를 수정·삭제할 수 있습니다.
- 색상: `[color=#cc3344]문장[/color]`
- 접어보기: `[fold=표제]접힌 내용[/fold]`
- 투명글: `[transparent]문장[/transparent]` — 선택하거나 키보드·터치로 초점을 맞춰 읽습니다. 보안용 비밀글 기능과는 별개입니다.
- 루비: `[ruby=읽는 법]본문[/ruby]`
- 서식은 React 요소로만 렌더링하며 색상은 6자리 HEX만 허용합니다. 원시 HTML·스크립트는 실행하지 않습니다.
- 사이트 소유자가 명시적으로 요청한 전체 데이터 초기화는 별도 서버 비밀값으로 인증하고 일회성 처리 표시로 중복 초기화를 차단합니다. 일반 관리자 UI에는 초기화 기능이 없습니다.

## 2026-09-26 업데이트

- 레스의 한 번 엔터도 줄바꿈으로 표시하고, 루비를 본문 바로 위에 배치합니다. 중첩 색상·굵게 서식도 문단을 쪼개지 않습니다.
- 일반 스레드에서 `>>번호`는 현재 스레드, `>>>스레드ID/번호`는 해당 스레드 레스로 이동합니다. 각 레스의 “앵커 복사”에서 슈퍼 앵커를 얻습니다.
- 연습장에서는 일반 스레드로 향하는 슈퍼 앵커만 작동합니다. 연습장 내부 앵커 및 연습장 레스를 향하는 링크는 비활성화합니다.
- 연습장의 1,500개 제한은 현재 남아 있는 레스 기준입니다. 숨긴 레스는 포함하며, 예전 삭제 표시 레스는 제외합니다. 삭제는 번호 대신 고유 ID로 처리하여 재정렬 후 다른 레스가 삭제되는 일을 막습니다.
- 로컬 통합 검증은 가득 찬 연습장의 삭제·재작성·동시 요청과 일반 스레드 번호 보존을 포함합니다.

## 예약 스레드와 시간표

- 스레드 작성 시 예약 게시를 선택합니다. 날짜와 시간 입력은 한국 시간(KST) 기준입니다.
- 시간표는 공개 예정 시각순으로 10개씩 페이지를 나눕니다. 제목·작성자·카테고리 표시와 목록 노출, 미리 열람 허용을 개별 설정합니다. 비밀 스레드는 기본적으로 시간표에 표시하지 않습니다.
- 목록에서 숨긴 예약은 작성자·공동 편집자·관리자가 “내 예약 · 편집 가능”에서 찾을 수 있습니다.
- 예약 중에는 누구도 레스를 작성할 수 없습니다. 편집 권한자는 내용을 수정할 수 있고 작성자는 공개 전까지 삭제할 수 있습니다. 공개 후 삭제는 관리자만 가능하며 공개된 스레드를 다시 예약 상태로 돌릴 수 없습니다.
- 공개 여부는 서버 시각과 scheduled_at을 비교해 각 요청에서 판정합니다. 별도 주기 작업 지연 없이 시각이 지나면 일반 목록·검색·레스 작성에 반영합니다. 열어 둔 예약 화면도 시각에 맞춰 갱신합니다.
- 비밀 스레드는 미리 열람을 허용해도 비밀번호가 필요합니다. 시간표에서 숨긴 메타 정보는 API에서도 제거합니다.

## 서식과 연습장 변경

- 입력한 줄바꿈과 연속 빈 줄, 앞뒤 줄바꿈을 저장하고 표시합니다.
- 새로운 주사위 예: `[dice:3x0..100!+5]`. 0~100에서 중복 없이 3개를 뽑고 각 값에 +5를 적용합니다. 보정으로 결과가 원래 범위를 벗어날 수 있습니다.
- 연습장 수정 저장은 포함된 주사위를 다시 굴립니다. 숨긴 레스의 원문은 연습장 작성자에게만 추가로 반환하여 본인 수정을 지원하며, 수정해도 가림 상태는 유지합니다.
- 사용법은 사이트의 별도 페이지로 옮겼습니다.
- 통합 검증은 실행마다 격리된 로컬 DB를 생성하므로 미리보기 데이터와 충돌하지 않습니다.
