# RP LAND 보안 점검 및 강화 — 2026-10-08

## 범위와 결과

현재 API 및 사용자 콘텐츠 표시 코드를 검토하고, 격리된 로컬 D1/Worker에서 계정·권한·비밀글·악성 입력·반복 요청을 검사했다. 운영 데이터 초기화나 공개 범위 변경은 수행하지 않았다.

기존 검사 외에 추가한 초기 방어 검사 20개 중 9개가 기대한 차단 조건을 충족하지 않았다. 이는 9개의 독립적인 고위험 취약점이라는 의미는 아니다. 탈퇴 비밀번호 추측/계정별 쓰기 남용 제한 부재와 요청 형식·크기·경로 검증 보완점을 재현한 결과다.

## 변경

- 탈퇴 비밀번호 검증과 관리자 설정 시도를 계정별 15분당 20회로 제한. 기존 로그인 계정별 제한 유지. 플랫폼 방문자 ID가 제공되는 경우 여러 아이디로 나눠 시도하는 로그인도 방문자별 15분당 100회 제한.
- 로그인 계정의 글·레스·저장 이름·카테고리·회원 변경 요청을 합산하여 15분당 300회로 제한. 실패한 변경 요청도 포함. 읽기와 로그아웃은 이 제한과 분리.
- JSON 요청 본문은 256,000바이트 및 기존 150,000문자 제한 적용. Content-Length가 없는 전송도 검사. 제한 초과 후 추가 데이터를 메모리에 누적하지 않고 버리며 요청 스트림을 마친 뒤 413 반환. 따라서 전체 전송량/전송 시간 제한을 대체하지는 않는다.
- JSON 객체만 허용하며 배열·null 등은 거절. Content-Type을 정확히 검사.
- 기존 Origin 검사와 함께 Sec-Fetch-Site: cross-site인 변경 요청을 거절.
- 허용된 API 경로·HTTP 메서드를 검사. 불필요한 경로 접미사와 객체 상속 속성 이름을 거절.
- 외부 이미지/링크에 referrerPolicy=no-referrer 적용. 외부 이미지 지연 로딩 추가.
- 검사 실행기 실패 시 로컬 Worker 로그를 남기도록 개선.

## 검증

- 신규 보안 검사: 28/28 통과. 잘못된 요청 차단, 권한 상승 거절, 비밀글 접근 제한, SQL 형태 입력의 데이터 처리, 반복 요청 제한, 정상 로그아웃, 최대 길이 Unicode 위키와 크기 초과/청크 전송 후 정상 조회 포함.
- 기존 통합 검사: 247/247 통과.
- 기존 악의적 입력/권한 회귀 검사: 186/186 통과.
- 서식/XSS 거절/줄바꿈/루비/앵커/주사위 렌더링 검사 통과.
- TypeScript 검사, 빌드, git diff --check 통과.

기존 통합 검사는 로컬 연결 재사용 이슈를 피하는 Connection: close 래퍼로 실행했으며 쓰기 요청을 재시도하지 않았다. 큰 요청 거절 뒤의 전송 문제는 본문을 제한된 메모리로 처리하고 남은 데이터를 버리는 방식으로 수정한 후 별도 후속 조회로 확인했다.

## 한계

독립 기관의 침투 테스트나 보안 인증은 아니다. 실제 브라우저 공격, 의존성 전체 CVE 감사, Cloudflare/Sites 내부 인프라, 대규모 분산 서비스 거부 공격은 검증 범위에 포함하지 않았다. 계정별 제한은 여러 계정·여러 출처에서 오는 분산 공격을 완전히 막지 못한다. 비공개 설정을 유지하며, 정식 공개 전 플랫폼의 트래픽 제한·모니터링·백업 접근 권한도 확인할 필요가 있다.
