# 카테고리 삭제와 재분류

- 총관리자만 전역 카테고리를 삭제한다. 확인 대화상자를 거치고 분류 참조 제거와 전역 삭제를 D1 batch로 처리한다. 위키·예약·비밀 스레드의 참조도 제거한다.
- 총관리자의 내 계정 하단에 유효한 분류가 없는 미삭제 스레드 목록을 20개씩 표시한다. 원래 미분류였던 스레드도 포함하고 위키와 연습장은 제외한다. 재분류하면 목록에서 빠진다.
- 작성자·총관리자·부관리자는 카테고리 전용 버튼으로 최대 3개를 지정하거나 전부 해제할 수 있다. 본문이나 갱신 시각은 변경하지 않는다.
- 공유 편집자의 본문 편집은 유지하되 카테고리 변경은 전용 API와 전체 편집 API 모두 차단한다.
- 비밀·미공개 글의 분류 전용 API는 작성자/관리자 권한만 확인하고 내용·비밀번호 해시는 반환하지 않는다. 본문 열람은 기존 비밀번호/예약 검사를 유지한다.
- 글 저장 시점에도 유효한 카테고리만 SQL 안에서 걸러 삭제와 저장이 동시에 일어나도 사라진 분류가 되살아나지 않는다.
- 새 카테고리 API 테스트 33개 통과. TypeScript, 운영 빌드, 기존 렌더 검증 통과. 실제 브라우저 UI 검증은 수행하지 않았다.
- 기존 운영 데이터와 운영자 설정 키는 초기화하지 않았다. 개인 D1 이전은 안내만 작성했다.
