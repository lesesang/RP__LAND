# 스레드 도구 개선 — 2026-10-08

- 30초 자동 갱신과 예약 공개 시각의 자동 화면 갱신을 제거했다. 예약 공개 여부는 서버 시각으로 계속 결정되며 수동 갱신/화면 진입 때 반영된다.
- 레스 수동 갱신은 작성칸 아래로 이동했다. 읽던 DOM 요소의 상대 위치를 보존하고 초기 앵커 이동을 한 번만 실행한다. 회원 정보가 같으면 상태 객체를 유지해 불필요한 재조회도 방지한다.
- 스레드·위키 대표 이미지 URL 하나를 저장하고 목록·본문에 표시한다. 빈 주소는 제거, 필드 생략은 기존 값을 보존한다. 시간표의 image 표시 설정을 끄면 API 응답에도 URL이 포함되지 않는다.
- 앵커 이동 전 읽기 전용 API가 대상 상태를 확인한다. 비밀글/예약 열람 검사를 그대로 적용하며 숨김·삭제 시 상태만 반환한다. 슈퍼 앵커의 표시 텍스트는 ↗번호로 축약했다. 숨김·삭제 레스에는 스크롤 대상 DOM ID를 부여하지 않는다.
- 계산기는 오른쪽 비모달 패널이다. 컴포넌트 상태에 수식과 최근 50개 결과를 유지하고, 스레드 이탈 시 폐기한다. 닫기·수동 갱신 시 유지한다. eval 없이 길이·중첩·유한값을 검증하는 산술 파서를 사용한다.
- 전체 초기화 작업의 일회성 식별자를 갱신했다. 실제 초기화와 운영자 키는 배포 후 별도 수행하며 키를 저장소에 기록하지 않는다.

- 리치 텍스트·주사위·계산기 렌더/단위 검증 통과.
